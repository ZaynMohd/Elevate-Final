🧠 MindCare AI – Mental Health Support Chatbot

MindCare AI is an AI-powered chatbot that provides mental health awareness, wellness tips, and emotional support using Python, Streamlit, LangChain, and Groq.

✨ Features

AI-powered mental health conversations

Stress and anxiety management tips

Mental health education

Interactive and user-friendly interface

Python | Streamlit | LangChain | Groq API
